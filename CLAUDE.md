## Claude Code specifics

- The project instructions are in `AGENTS.md` (imported above). Follow them.
- Use the `dotnet` commands listed there to build and test after every change. If `dotnet` is
  not on the PATH, use `"C:\Program Files\dotnet\dotnet.exe"`.
- The person you are helping is likely a design student without much programming experience.
  When they ask for something vague ("make the layers nicer"), ask one or two concrete
  questions about what they see in Grasshopper before changing code.
- Do not commit or push unless they ask. When they ask, write a short, plain commit message
  describing the visible change.
